# Eder Gutiérrez — Portfolio (Build Artifacts)

**Note:** This repository only contains the compiled HTML/CSS output for GitHub Pages. 

This static site was **100% generated from scratch** using a custom Static Site Generator (SSG) I built in Python.

### ⚙️ How it works under the hood
The Python engine reads raw Markdown files, parses them into an Abstract Syntax Tree using the Composite Pattern, and renders pure, standard HTML.
